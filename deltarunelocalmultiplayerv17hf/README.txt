Deltarune Local Multiplayer Mod 
By: Yomsman
For Deltarune Version 1.05  <----- KNOW WHAT VERSION  YOU NEED!

Note: There are additional settings in the mod menu config
you can access in a darkworld overworld zone.

Controls:

To customize controls access the mod menu config while 
in a darkworld overworld zone.

In this menu you can also access controller settings
for all players and set the controller each player is using
and customize their controls.

Here are the default controls for keyboard:

P1: Arrow Keys, Z, X, C
P2: WASD, J, I
P3: TFGH, M, K
Universal: P (Teleport players to P1), N (Toggle No clip for P2 and P3 outside of board)
Player Amount (Hotkey): F1 (1 Player), F2 (2 Players), F3 (3 Players)

Here are the default controls for Controller:

All Players: Left Stick / DPAD (Move), A (Interact), B (Cancel), Start (Teleport players to P1)
P1: Y (Menu Key)
P2 & 3: Select (Toggle No Clip)

Install Instructions (With DELTAMOD):

First you need DELTAMOD which you can get from here: https://gamebanana.com/tools/20575

Once DELTAMOD is running you click import mod on the bottom and import this mod in its ZIPPED format.
It is important that this entire folder is still zipped up when you do this and if done correctly it should work and you are able
to activate and deactivate the mod as you please.

Install Instructions (Without DELTAMOD):

Ideally, do this in a copied folder of your copy of Deltarune so you are not changing your 
main games data.

First make sure you download DeltaPatcher here: https://www.romhacking.net/utilities/704/

Then run the DeltaPatcher.exe after extracting the downloaded file.

For the original file locate to the chapter number you are trying to apply the mod for the directory
will be something like: DELTARUNE/chapter3_windows

Inside double click on data.win.

Then for the xdelta patch use the (Chapter#)LocalMultiplayer(ver).xdelta as the patch file.

I would recommend using Parsec to connect to the PC you will be playing on and on the 
host PC add the game as a non steam game by pressing Games-> Add A Non Steam Game To My Library 
then navigating to the Deltarune.exe outside of any chapter folders.
